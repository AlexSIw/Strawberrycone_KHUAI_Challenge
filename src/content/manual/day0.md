# 운영 매뉴얼 — D-5 · 물리 구축 (랙 · 전원 A/B · 배선)

수강신청까지 5일. 새로 온 서버 3대(WEB-01 = 웹 서버, WEB-02 = 예비 웹 서버, DB-01 = 신청 기록을 보관하는 데이터 창고)를 1번 랙에 달고, 전원과 케이블을 연결하는 날이야.
순서는 랙 장착 → 전원 → 케이블. 손에 잡히는 것(물리)부터야. 아직 학생 접속은 없어.
다른 장비(코어 스위치, 방화벽, 2~4번 랙 서버들, 전기·냉방 시설)는 선배들이 이미 설치해 뒀어.

## 이번 날 목표
1. 방 5개 둘러보기: 서버실 · 네트워크실 · 전기실 · 냉각실 · 관제실
2. 관제실 설계 보드에서 퀴즈 풀기 (방을 다 본 뒤에 열려)
3. 서버실 1번 랙에 서버 3대 장착 (랙 앞에서 E)
4. 전기실 PDU에서 서버 3대에 전원 A·B 두 줄 모두 꽂기
5. 네트워크실 스위치(TOR-01)에 서버 케이블 연결 (배선표: WEB-01 → 1번, WEB-02 → 2번, DB-01 → 3번 포트)
6. 관제 화면(NMS)에서 TOR-01을 열어 포트 불빛 확인
7. 관제 화면 FMS 탭에서 전기·냉방 상태 둘러보기
- 목표는 하나씩 차례로 열려. 케이블은 아무 빈 포트에 꽂아도 인정되지만, 배선표대로 꽂는 게 내일 일이 편해.

## 조작법
- 이동: WASD 또는 방향키 · 상호작용: 장비 앞에서 E · Esc: 창 닫기
- 관제 화면(NOC): 관제실 모니터 앞에서 E. NMS(네트워크 장비 감시) · SMS(서비스 감시) · FMS(시설 감시) 탭이 있어.
- 막히면 쿠사수 무전기(힌트), 개념 도감에서 지금까지 모은 개념 카드를 다시 볼 수 있어.

## 방과 장비 지도
| 방 | 장비 | 하는 일 |
|---|---|---|
| 서버실 | 랙 1~4 | 서버를 층층이 끼우는 선반. 1번 랙 = 오늘 작업, 2~4번 = 선배들이 설치해 둔 서버 |
| 네트워크실 | 스위치(TOR-01) · 코어·방화벽 · 패치 패널 | TOR-01 = 1·2번 랙 서버를 묶는 랙 스위치, 코어 = 데이터센터 네트워크의 중심 |
| 전기실 | PDU · UPS | PDU = 랙 전용 멀티탭(A/B 두 줄), UPS = 정전 때 버티는 배터리 (보기만 가능) |
| 냉각실 | 항온항습기(CRAC) | 온도·습도를 일정하게 맞추는 서버실 전용 에어컨 (보기만 가능) |
| 관제실 | 모니터(관제 화면) · 관리 PC · 쿠사수 · 설계 보드 | 데이터센터 전체를 지켜보는 방 |

## 핵심 개념
### 데이터센터 · 클라이언트-서버 (비유: 컴퓨터들이 사는 아파트 · 손님과 주방)
- 서버가 24시간 일할 수 있게 전기·냉방·네트워크를 대신 챙겨주는 건물이야.
- 학생 노트북(클라이언트: 요청하는 쪽)이 버튼을 누르면 요청이 인터넷을 거쳐 데이터센터 서버로 오고, 서버가 처리해서 응답을 돌려줘.

### 랙 · U (비유: 서버 전용 책장과 책장 한 칸)
- 서버는 랙의 칸에 끼워. 칸 높이 단위가 U야(1U ≈ 4.45cm).
- 랙 맨 위에는 그 랙 서버들을 묶어 주는 스위치(ToR: Top of Rack)가 있어. 여기선 TOR-01.

### 이중 전원 A/B · PDU (비유: 랙 전용 멀티탭 두 줄)
- 서버에는 전원부가 두 개 있어. A줄과 B줄에 하나씩 꽂으면 한 줄(PDU 하나)이 끊겨도 꺼지지 않아.
- 한 줄만 꽂으면 그 줄이 단일 장애점(SPOF: 하나만 고장 나도 전체가 멈추는 곳)이 돼.

### UPS · 발전기 · ATS · EPS실·TPS실 (시설, FMS에서 보기만)
- 정전되면 UPS(비상 배터리)가 몇 분 버티는 사이 발전기가 돌아. ATS(자동 절체 스위치)가 전기 길을 한전 → 발전기로 자동으로 바꿔.
- 건물 층마다 전기 배선 통로(EPS실)와 통신선 통로(TPS실)가 있어. 캠퍼스 건물 네트워크 선은 TPS실을 타고 데이터센터까지 와.
- 시설은 시설팀 담당이야. 우리는 FMS 화면으로 지켜보고, 이상하면 "시설팀 통보"로 알려.

### 포트 LED · CRC 오류 (비유: 신호등 · 찢어진 편지)
- 포트(케이블 꽂는 구멍) 옆 불빛: 초록 = 케이블 양쪽이 연결돼 신호가 오감(link UP), 꺼짐 = 연결 없음.
- 초록·주황이 번갈아 깜빡이면 문제가 있다는 뜻. 케이블이 반쯤 망가지면 연결은 살아 있어도 깨진 데이터가 섞여.
- 받은 데이터의 검산이 안 맞은 횟수를 CRC 오류라고 세. 관제 화면(NMS)에서 장비를 열면 포트마다 이 숫자가 보여.

### OSI 7계층 · L1 물리 (비유: 7층짜리 우체국의 1층 = 실제 도로)
- 통신을 7층으로 나눠 보는 지도. L1은 데이터가 실제로 지나가는 케이블과 전기 신호야.
- 문제 찾기는 언제나 L1(케이블·불빛)부터!

## 쓸 수 있는 도구
- 오늘은 터미널(글자로 명령을 치는 창)을 쓰지 않아. 관리 PC 터미널은 내일(D-4)부터.
- 랙(서버실 1번 랙에서 E): 카트의 서버 상자를 끌어서 랙 빈 칸에 꽂기.
- 전원(전기실 PDU에서 E): 서버마다 A·B 플러그 꽂기.
- 케이블(네트워크실 스위치에서 E): 서버 포트를 끌어서 TOR-01 포트에 꽂기. 꽂힌 케이블은 테스트하고 새것으로 바꿀 수 있어. 패치 패널(E)에서도 케이블 점검·교체를 할 수 있어.
- 관제 화면(관제실 모니터에서 E):
  - NMS 탭: 장비 지도. 장비를 누르면 포트마다 상태(불빛), CRC 오류 숫자, 장비 로그가 보여.
  - FMS 탭: UPS 부하·배터리, PDU A/B 전류, 발전기 대기 상태, 랙 온도·습도.
  - 경보 목록: 장애가 감지되면 여기 떠. "확인(ACK)"을 누르면 "봤다"는 표시.

## 결과 읽는 법
- 랙 미니게임: 장착한 서버 LED가 꺼져 있으면 아직 전기가 없어서야(정상, 다음 단계가 전원).
- 전원 미니게임: 서버마다 A·B 두 플러그가 다 꽂혀야 목표 완료.
- 케이블 미니게임: 꽂자마자 LED 초록 = 연결 성공. 꺼져 있으면 서버 전원부터 확인.
- 관제 화면의 경보는 두 종류로 와:
  - 장비가 스스로 알리는 것(trap·syslog): 바로 뜸.
  - 관제 시스템이 숫자를 주기적으로 물어보고 알아채는 것(poll, 폴링): 다음 순찰(약 15초마다) 때 떠. 그래서 사용자가 먼저 알아챌 때도 있어.

## 장애 유형별 점검 순서
### A. 포트 불빛이 초록·주황으로 깜빡임 / CRC 오류 증가 (반쯤 망가진 케이블)
증상 예: "스위치 포트 불빛 하나가 초록이랑 주황으로 번갈아 깜빡여요" · 경보 "TOR-01 포트 입력 오류(CRC) 증가"
1. 관제 화면 NMS에서 TOR-01을 열어 포트마다 CRC 오류 숫자를 봐.
   - 정상: 모든 포트 0 근처에서 그대로.
   - 비정상: 한 포트만 숫자가 계속 늘어남. 불빛은 초록인데(연결은 살아 있음) 데이터가 깨지고 있는 것.
2. 그 포트에 어느 서버가 꽂혀 있는지 따라가.
3. 전원은 멀쩡하고 연결도 살아 있는데 데이터만 깨진다면, 전기 신호가 지나는 길(L1, 케이블) 자체를 의심해.
4. 네트워크실 스위치(또는 패치 패널)에서 그 케이블을 테스트하고, 문제가 있으면 새 케이블로 바꿔. 바꾸면 불빛이 초록으로 돌아오고 오류 숫자가 더 이상 안 늘어나.
- 이미 쌓인 CRC 숫자는 지워지지 않아. "더 늘어나지 않는지"를 봐.
- 이 장애는 D-4 이후에도 서버 케이블 어디서든 생길 수 있어. 볼 곳은 같아(NMS 포트 오류 숫자 → 케이블).
- 교훈: 케이블이 반쯤 망가지면 불은 들어와도 깨진 데이터가 섞여. 문제 찾기는 L1부터!

### B. 목표가 안 넘어감
- 랙: 서버 3대(WEB-01, WEB-02, DB-01) 모두 1번 랙에 꽂았는지.
- 전원: 서버마다 A와 B를 둘 다 꽂아야 해. 한 줄만 꽂으면 완료가 안 돼.
- 케이블: 서버마다 TOR-01 포트에 꽂고, 불빛이 초록이어야 해(서버 전원이 들어와 있어야 초록이 돼).
- 포트 불빛 확인: 관제 화면 NMS 탭에서 TOR-01을 눌러 열어야 해.
- FMS: 관제 화면에서 FMS 탭을 열면 돼.
- 퀴즈: 방 5개를 다 둘러봐야 열려. 질문은 "학생이 버튼을 누르면 요청은 어디로 갈까?" 정답을 바로 말하지 말고 "손님과 주방" 비유로 생각하게 해줘.

## 힌트 줄 때 참고
- 초보자는 용어가 낯설어. 장비 이름을 말할 땐 하는 일을 비유로 같이 말해줘.
- CRC 장애에서 "케이블 교체", "새 케이블" 같은 정답 행동이나 어느 서버인지는 직접 말하지 말고, 볼 곳(NMS의 포트별 오류 숫자, 그 포트에 꽂힌 케이블)을 가리켜줘.
- 정전·전기 설비 문제는 시설팀 담당이야. 플레이어가 직접 고치는 게 아니라 FMS로 지켜보고 알리는 거야.
